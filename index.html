Visualização nacional com clima real via Open-Meteo, corredores rodoviários brasileiros, importação de CSV da PRF e integração opcional com TomTom Traffic API para fluxo de trânsito em tempo real.

Controles do mapa

Sem chave TomTom, o mapa não inventa congestionamento ao vivo: usa clima real + pontos rodoviários de referência e dados importados. O CSV fica só no seu navegador.

Como ler o mapa

Verde indica baixo risco; amarelo/laranja indicam atenção; vermelho indica risco elevado por chuva, vento, calor/frio extremo, baixa visibilidade presumida ou tráfego importado/API.

  • Clima: Open-Meteo
  • Mapa base: OpenStreetMap
  • Trânsito real opcional: TomTom Traffic API
  • CSV sugerido: dados abertos de acidentes da PRF
