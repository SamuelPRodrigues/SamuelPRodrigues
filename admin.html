Administração do mapa

Edite nome, intervalo de atualização, filtros padrão e corredores monitorados. Nesta versão estática do GitHub Pages, as alterações são salvas no navegador do administrador e podem ser exportadas como JSON para substituir o arquivo data/config.json.

Ver página pública
Para auto-atualização sem input, a página pública busca a API da Open-Meteo automaticamente no carregamento e depois no intervalo definido aqui.

Observação: proteção real de administrador exige backend/login. Em GitHub Pages puro, qualquer pessoa que saiba o link consegue abrir esta página. Para produção, use Netlify/Vercel com autenticação ou um backend.
